## 优惠码怎么填？步骤和失效判断

真等到出码的那天，操作很简单，但顺序别错：

1. 选好套餐、计费周期和机房，点 Add to Cart；
2. 进购物车，找到 Promotional Code 输入框，粘贴优惠码；
3. 点 Validate Code，页面价格变成折后价才算生效；
4. 提示 Invalid 或 expired 就是码失效了，别硬结账。

两个常见坑：一是**先付款后想起来没用码**，这种情况下订单不能补差价；二是以为所有码都能叠加限量版，实际上促销码和特殊定价套餐经常互斥，Validate 之后价格没变就说明这个套餐用不了这个码。

支付方式支持支付宝、微信、PayPal、信用卡和银联，国内用户下单没有门槛。付款后服务器一般一两分钟内开通，IP 和 root 密码在 KiwiVM 面板里能直接看到。
